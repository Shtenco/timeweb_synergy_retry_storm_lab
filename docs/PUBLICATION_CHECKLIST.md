# Редакционный чек-лист Timeweb Cloud — статья №18

## Проверено

- [x] Воспроизводимый локальный Python-стенд: 6 политик, HTTP, управляемые отказы.
- [x] Исходные результаты: JSON, CSV, SHA-256 и код для повторной проверки.
- [x] Локальные тесты: 16/16; проверка архива: 4 320 логических операций, 4 857 HTTP-вызовов, 18 серий.
- [x] Точные ограничения: один Linux-хост и loopback HTTP, не производственный кластер.
- [x] Русский README, методика, CI и открытый GitHub-репозиторий.
- [x] Google Docs: 15 страниц, 14 встроенных технических PNG, 14 подписей.
- [x] В PDF не обнаружены изображения без подписей и пересечения иллюстраций с подписями.
- [x] Структура материала: три вводных абзаца, H2 с символом ❯, выводы, ссылки и практические рекомендации.
- [x] Заголовок отражает абляцию, а не обобщает её на все настройки circuit breaker.
