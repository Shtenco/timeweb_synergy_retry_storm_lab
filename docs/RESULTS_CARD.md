# Результаты эксперимента №18

Локальная исследовательская серия: 240 исходных запросов × 6 политик × 3 повтора = 4 320 операций. Реальный loopback HTTP; всего 4 857 серверных HTTP-попыток.

| Политика | Успех, медиана | HTTP amplification | p95 всех операций |
|---|---:|---:|---:|
| `direct` | 47.92% | 1.00× | 40.2 мс |
| `naive_retry` | 69.58% | 1.82× | 120.7 мс |
| `jitter_retry` | 69.58% | 1.82× | 159.2 мс |
| `breaker_only` | 32.08% | 0.39× | 4.8 мс |
| `budget_bulkhead` | 56.25% | 1.30× | 46.7 мс |
| `protected` | 32.92% | 0.41× | 15.2 мс |

**Самый честный редакционный акцент:** сравнение `budget_bulkhead` и `protected` отличается включением одного общего circuit breaker; 56,25% против 32,92% — снижение на 23,33 процентного пункта. Это демонстрирует настройку/гранулярность breaker, а не бесполезность паттерна.

Для каждой точки доступны три полных измерения, `operations.csv`, `backend_events.csv` и контрольные суммы. Ошибочные/неудобные результаты не исключались.

Проверка качества: 16 тестов `unittest` (локальный запуск), исходные данные проверены `verify_results.py`. 9 технических PNG построены из сохранённого отчёта, не сгенерированы как фантазия.

**Граница выводов:** 1 хост, 127.0.0.1, Python stdlib, 3 серии, 240 запросов, 1 фиксированный fault-plan. Не тест Timeweb Cloud или другого облачного сервиса.
